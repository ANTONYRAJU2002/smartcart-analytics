# SmartCart Analytics

SmartCart Analytics is a data-driven e-commerce analytics system developed to analyze sales performance, customer behavior, and product demand.

## Structure

- **backend/**: Flask-based REST API and Analytics Engine.
- **frontend/**: React-based User Interface (Vite).
- **data/**: Data storage (SQLite, Raw CSVs).

## Setup

### Backend
1. Navigate to `backend/`.
2. Install dependencies: `pip install -r requirements.txt`.
3. Run server: `python run.py`.

### Frontend
1. Navigate to `frontend/`.
2. Install dependencies: `npm install`.
3. Run dev server: `npm run dev`.
